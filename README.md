# Student Performance Analyzer

Учебный проект на Python для анализа успеваемости и посещаемости студентов на основе данных из CSV-файла.

Программа загружает `students.csv`, считает базовую статистику, находит лучшего и худшего студента, выявляет студентов с низкой посещаемостью и строит графики с помощью Matplotlib.

## Возможности

- подсчёт количества студентов;
- средний балл по каждому предмету;
- определение лучшего и худшего предмета (по среднему баллу);
- определение студента с максимальной и минимальной суммой баллов;
- вывод студентов с посещаемостью ниже 70%;
- 4 графика:
  1. средний балл по предметам (столбчатая диаграмма);
  2. зависимость посещаемости от суммы баллов (точечная диаграмма);
  3. успеваемость студентов (столбчатая диаграмма);
  4. посещаемость студентов (столбчатая диаграмма).

## Формат данных

Данные читаются из файла `students.csv`, который должен лежать рядом с `main.py`, в кодировке UTF-8.

Требования к структуре:

- **первый столбец** — имя студента (`name`);
- **последний столбец** — процент посещаемости (`attendance`);
- **столбцы между ними** — оценки по предметам (числа).

Пример:

```csv
name,math,physics,programming,english,attendance
Alexander,85,78,92,81,95
Ivan,72,80,75,68,82
Dmitry,91,88,95,90,97
```

Названия предметов берутся из заголовка CSV автоматически, поэтому количество предметов можно менять.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <repository-url>
cd Student-Performance-Analyzer
```

2. Установите зависимости:

```bash
pip install matplotlib PyQt6
```

`PyQt6` нужен, потому что в коде выбран бэкенд `QtAgg`. Если не хотите ставить Qt, удалите строку `matplotlib.use('QtAgg')` — Matplotlib выберет доступный бэкенд сам.

3. Запустите программу:

```bash
python main.py
```

Результаты анализа выводятся в консоль, а графики открываются по очереди в отдельных окнах (следующий график появляется после закрытия предыдущего).

## Описание функций

| Функция | Что делает |
| ------- | ---------- |
| `calculate_average(data, subject)` | Считает средний балл по выбранному предмету |
| `students_count(data)` | Выводит количество студентов |
| `average_mark_on_each_subject(data, common_keys)` | Считает средние по всем предметам, определяет лучший и худший предмет, строит график средних баллов |
| `best_student(data, common_keys)` | Находит студента с максимальной суммой, строит точечную диаграмму «посещаемость ↔ баллы» и график успеваемости |
| `worst_student(data, common_keys)` | Находит студента с минимальной суммой |
| `students_with_low_attendance(data)` | Выводит студентов с посещаемостью ниже 70% |
| `graphic_attendance(data)` | Строит график посещаемости студентов |

## Как это работает

```text
students.csv → csv.DictReader → список словарей → статистика и поиск min/max → графики Matplotlib
```

Каждая строка CSV превращается в словарь, а все студенты собираются в список словарей `data`. Список столбцов (`common_keys`) берётся из заголовка файла без столбца `name`.

## Известные особенности

- В `best_student` и `worst_student` сумма считается по всем столбцам из `common_keys`, а он включает `attendance`. То есть посещаемость сейчас входит в «сумму баллов». Для чистой суммы по предметам нужно исключить последний столбец, как это уже сделано в `average_mark_on_each_subject`.
- В `worst_student` начальное значение минимума равно `1000` — при очень больших суммах баллов функция сработает неверно.
- Лучший и худший студент определяются по первому найденному значению: при равных суммах выбирается первый в файле.
- Точечная диаграмма показывает связь между посещаемостью и баллами, но не доказывает причинно-следственную связь.
- Построение графика находится внутри `best_student` и `average_mark_on_each_subject`, а не в отдельных функциях.
